# Implementation Tacticals

Bounded implementation plans and execution records live here.

Use zero-padded numeric prefixes for new tactical documents:
`001-topic.md`, `002-next-topic.md`, and so on. A tactical should define its
scope, non-goals, ordered work, acceptance criteria, and validation. Keep it
updated as implementation proceeds so the completed document records what
actually landed, what was verified, and what was deliberately deferred.

Living truths and continuing concerns belong in [`../topics/`](../topics/README.md).
Tacticals own finite implementation campaigns and may link to a topic when the
work changes a continuing concern.
