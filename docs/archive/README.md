# Documentation Archive

This directory preserves historical documentation that may still provide
useful context but is not maintained as current guidance.

It includes completed or uncertain plans, designs, investigations, performance
notes, roadmaps, task records, playbooks, and project snapshots. Statements,
paths, links, and status markers inside these documents may be stale.

Do not update archived documents as part of normal implementation work. If an
archived concern becomes active again, reconcile it against the code and move
the durable current truth into [`../topics/`](../topics/README.md), a normative
contract, or another clearly active document.
